# Christian Pure Bible Search

Type a worry, a question or a verse, such as *anxiety*, *a prayer before a meal* or *Psalm 23*. You get what the Bible says about it, a prayer to pray, and Christian Pure articles to read next.

This Space runs the same app you can install on your own computer, where it works with no internet connection: [github.com/christianpure/bible-search](https://github.com/christianpure/bible-search).

Bible text: Berean Standard Bible (public domain). Subjects: OpenBible.info (CC BY 4.0). Prayers: [christianpure.com](https://christianpure.com/?utm_source=huggingface&utm_medium=app&utm_campaign=bible-search-app).
